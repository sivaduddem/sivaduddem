## Herculanum

The episode-card lettering is **Herculanum LT Std Roman**, designed by Adrian Frutiger and published by Linotype. The font software is © 1990, 2001, 2002 Adobe Systems / Linotype. Herculanum is a Linotype trademark.

The title images (`assets/title-*.png`) are flat pictures of words set in that font: SIVA DUDDEMPUDI, WATER, EARTH, FIRE, AIR, and TEA. The `.ttf` is not in this repository, and it should not be added. A public repo would be redistributing the font software.

A desktop license is what covers making flat images from the font. The copies circulating as "free for personal use" are not Linotype's license. If this page stays public, the type should be a face you have a license for, or the title images should come out.
